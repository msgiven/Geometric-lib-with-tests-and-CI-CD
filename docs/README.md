# Библиотека геометрических функций

## Общее описание проекта

Проект представляет собой библиотеку математических функций для работы с геометрическими фигурами. В рамках проекта реализованы модули circle.py и square.py, которые содержат функции для вычисления площади и периметра круга и квадрата по заданным параметрам.

  
## Описание функций

### Модуль circle.py
#### Функция `area(r)`
- Назначение: вычисляет площадь круга по заданному радиусу.
- Параметры: r (int или float) — радиус круга.
- Возвращаемое значение: area (float) — площадь круга.

Пример вызова:
```python
import circle
print(circle.area(3))
```
_Результат: 28.274333882308138_

#### Функция `perimeter(r)`

- Назначение: вычисляет периметр круга по заданному радиусу.
- Параметры: r (int или float) — радиус круга.
- Возвращаемое значение: circumference (float) — периметр круга.

Пример вызова:
```python
import circle
print(circle.perimeter(3))
```
_Результат: 18.84955592153876_


### Модуль square.py

#### Функция `area(a)`

- Назначение: вычисляет площадь квадрата по заданной стороне.
- Параметры: a (int или float) — сторона квадрата.
- Возвращаемое значение: area (int или float) — площадь квадрата.

Пример вызова:
```python
import square
print(square.area(5))
```
_Результат: 25_

#### Функция `perimeter(a)`

- Назначение: вычисляет периметр квадрата по заданной стороне.
- Параметры: a (int или float) — сторона квадрата.
- Возвращаемое значение: perimeter (int или float) — периметр квадрата.

Пример вызова:
```python
import square
print(square.perimeter(5))
```
_Результат: 20_
